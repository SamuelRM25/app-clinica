# ClinicApp: página de presentación

Sitio público de **clinicapp.gt**. Esta rama solo contiene la página; la aplicación vive en `Base` y en las ramas `hospital/*`.

| Archivo | Para qué sirve |
|---|---|
| `index.php` | Página completa (HTML, CSS y JS en un solo archivo, sin dependencias) |
| `send_contact.php` | Recibe el formulario de contacto y envía el correo |
| `logo.png` | Logo de RS Solutions |

**Publicar:** subir los tres archivos a `public_html/` del dominio principal en Hostinger.
